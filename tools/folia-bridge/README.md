# MyFinder 任务栏音乐与设备电量显示

为 [Folia](https://github.com/chthollyphile/folia) 提供的桌面任务栏联动模组，配合桌面端工具 [**MyFinder Device Battery**](https://github.com/spake404/myfinder-device-battery) 使用，将 Folia 的播放状态、实时歌词、播放队列、歌单收藏与控制指令桥接到 Windows 任务栏音乐控制栏与悬浮双胶囊面板，与无线鼠标、耳机、键盘电量同栏显示。

## 主要功能

- **任务栏音乐控制栏（两种样式）**
  - **方案 A（紧凑开关）**：在任务栏电量条旁显示单个音符入口，播放中自动亮起主题色并带底部状态细条，点击展开悬浮双胶囊。
  - **方案 B（常驻控制）**：直接在任务栏展示「上一首 / 播放暂停 / 下一首 / 胶囊面板 / 循环模式」5 个按钮，无需切窗口即可切歌与切换循环。
  - 支持 Windows 11 横排任务栏窗口按钮区自动避让预留，避免被任务栏多窗口遮挡。
- **悬浮双胶囊控制面板**
  - **顶部功能胶囊**：折叠音量条、喜欢/取消喜欢、收藏到歌单、随机打乱队列、唤醒 Folia 主界面（支持托盘最小化时拉起置前）、桌面歌词开关、任务栏样式切换。
  - **底部主控胶囊**：播放/暂停、切歌、可拖拽跳转的播放进度条、循环模式切换、播放队列入口。
  - 支持 5 种 120fps 菜单弹出动效（错峰上滑、灵动弹出、水滴展开、轻柔淡入、弹性上浮）与浅色/深色主题自适应。
- **播放队列 & 收藏到歌单**
  - **播放队列**：时间轴式亚克力毛玻璃窗口展示当前队列，支持点击任意曲目直接切歌。
  - **收藏到歌单**：在悬浮面板上方直接展开用户的网易云歌单列表（含歌单与当前曲目封面缩略图），一键将当前播放歌曲加入指定歌单。

## 搭配使用

本模组负责在 Folia 内采集播放状态、歌词、队列与歌单信息，并通过本地环回接口与桌面端程序通信；任务栏音乐栏与悬浮胶囊由桌面端程序绘制：

1. 在 Folia 模组市场安装并启用 **MyFinder 任务栏音乐与设备电量显示**（`myfinder-folia-bridge`）。
2. 下载并运行桌面端 [**MyFinder Device Battery**](https://github.com/spake404/myfinder-device-battery/releases)（v1.5.0 及以上版本）。
3. 在桌面端「Folia 播放控制」页面即可看到连接状态，并可随时切换方案 A / 方案 B 与各类交互开关。

> 注：桌面端 `MyFinder Device Battery` 也自带同名桥接模组的自动部署功能；通过 Folia 模组市场安装本签名版本可获得官方认证标识，并支持在 Folia 内接收模组更新。

## 权限说明

- `playback.read`：读取当前播放曲目信息、播放/暂停状态、进度、时长、音量、循环模式、喜欢状态、实时歌词及播放队列。
- `playback.control`：响应任务栏与悬浮胶囊的播放/暂停、上一首/下一首、进度跳转、音量调节、循环模式切换、随机打乱队列、喜欢及队列切歌指令。
- `platform.netease.read` / `platform.netease.write` / `experimental: ["platform.raw"]`：用于「收藏到歌单」功能——读取当前登录账号的网易云歌单列表（`user_playlist`）以及将当前歌曲添加到指定歌单（`playlist_tracks`）。

## 隐私与本地通信安全

- 本模组**不联网、不收集或上传任何用户数据**。
- `main.cjs` 仅在本地环回地址 `127.0.0.1` 上绑定系统分配的随机端口，每次启动生成 48 位十六进制随机令牌（`x-myfinder-token`），并将端口与令牌写入当前用户的 `%LOCALAPPDATA%\MyFinderDeviceBattery\folia-bridge.json` 供本地桌面端读取鉴权。
- 模组卸载或停用时自动关闭本地监听并清理临时桥接文件。
